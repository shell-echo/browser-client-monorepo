# Web application

[Project home](../../README.md) · [Development guide](../../docs/development.md#web-template) · [简体中文](../../docs/zh-CN/development.md#网站模板)

Next.js App Router website with the shared shadcn/ui design system and an `/extension` connection example.

Run from the repository root after `pnpm install --frozen-lockfile`:

```sh
pnpm dev:web
pnpm app build web
pnpm app start web
```

Open http://127.0.0.1:3000. Edit pages in `src/app/` and interactive navigation in `src/components/site-header.tsx`. Inter is bundled through the shared UI package; this application does not use the scaffold's default Geist setup.

See [testing](../../docs/testing.md), [deployment](../../docs/deployment.md), and [application lifecycle](../../docs/applications.md). This instance README may be regenerated by `reinit`; persistent project instructions live in the root README and `docs/`.
