# Browser extension

[Project home](../../README.md) · [Development guide](../../docs/development.md#browser-extension) · [简体中文](../../docs/zh-CN/development.md#浏览器扩展)

Chrome / Edge Manifest V3 extension built with Vite, React, and CRXJS, with popup, options, side panel, and an authorized native-Port SDK.

Run from the repository root after `pnpm install --frozen-lockfile`:

```sh
pnpm dev:extension
pnpm app build extension
pnpm extension:package extension
```

For development, enable Developer mode in `chrome://extensions` or `edge://extensions` and load `apps/extension/dist-dev`. Production output is `apps/extension/dist`. Use `pnpm preview:extension` for a separate ordinary-webpage UI preview; it shares port `5174` with extension development. Configure exact trusted website origins in `src/bridge-policy.ts`.

See [testing](../../docs/testing.md), [deployment](../../docs/deployment.md), and [application lifecycle](../../docs/applications.md). This instance README may be regenerated by `reinit`; persistent project instructions live in the root README and `docs/`.
