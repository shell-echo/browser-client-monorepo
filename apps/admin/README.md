# Admin application

[Project home](../../README.md) · [Development guide](../../docs/development.md#admin-templates) · [简体中文](../../docs/zh-CN/development.md#管理后台模板)

Vite + React + React Router starter with `/login`, `/dashboard`, responsive navigation, and shared themes.

Run from the repository root after `pnpm install --frozen-lockfile`:

```sh
pnpm dev:admin
pnpm app build admin
```

Open http://127.0.0.1:5173. Customize `src/pages/` and `src/components/`. Login and dashboard actions are UI examples; connect authentication, access control, and business APIs before using them in a product. Production hosting needs an SPA fallback.

See [testing](../../docs/testing.md), [deployment](../../docs/deployment.md), and [application lifecycle](../../docs/applications.md). This instance README may be regenerated by `reinit`; persistent project instructions live in the root README and `docs/`.
